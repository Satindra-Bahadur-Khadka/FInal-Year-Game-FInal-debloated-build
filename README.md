This code is on Project Absolution, a Metroidvania game where its goal is to improvise genre tropes and to outdistance some of the genre's biggest weaknesses. It draws upon thorough research and player feedback to learn where the game could be better in the future, e.g., stale mechanic, player agency dearth, and narrative integration failure. 

Time manipulation and decision-consequence processes, advertising immersive narrative and unique visual style. Although the research provides a decent base from which to build, it also includes affordances for optimization in the tradeoff between game mechanics and artistic fidelity. 

This study uncovered the bedrock from which a game can be laid to alter player expectations, as well as build upon player expectations from the Metroidvania experience.
